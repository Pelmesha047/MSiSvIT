# Лабораторная работа №2: Анализ метрик сложности потока управления программой

В данной лабораторной работе реализована программа для вычисления метрик сложности потока управления (Control Flow Metrics) для исходного кода на языке Perl в соответствии с методическими указаниями.

---

## 📌 Вычисляемые метрики

1. **Метрика Маккейба (Цикломатическая сложность графа управления)**
   $$Z(G) = e - v + 2p$$
   - $e$ — число дуг (ориентированных переходов между операторами);
   - $v$ — число вершин (операторов и управляющих блоков);
   - $p$ — число компонентов связности графа (для корректных программ $p = 1$).
   - *Значение $Z(G)$ указывает минимальное число базисных независимых путей для полного тестирования ветвлений.*

2. **Метрики Джилба (Логическая сложность)**
   - **Абсолютная сложность $CL$**: общее количество операторов выбора и условных переходов (`if`, `elsif`, `unless`, `while`, `until`, `for`, `foreach`, `when`, `?:`).
   - **Относительная сложность $cl$**: насыщенность программы условными операторами $cl = \frac{CL}{N}$, где $N$ — общее число операторов.
   - **Максимальный уровень вложенности $CLI$**: максимальная глубина вложенности условных операторов и циклов.

3. **Метрика граничных значений (Boundary Value Metric)**
   - **Абсолютная граничная сложность $S_a$**: сумма скорректированных сложностей всех вершин графа $G$:
     $$S_a = \sum_{v \in V} S(v)$$
     - Скорректированная сложность для принимающих вершин ($deg^+ \le 1$) равна $1$.
     - Скорректированная сложность для конечной вершины равна $0$.
     - Скорректированная сложность вершины выбора ($deg^+ \ge 2$) равна количеству вершин подграфа (исключая саму вершину выбора), доступных до границы подграфа.
   - **Относительная граничная сложность $S_0$**:
     $$S_0 = 1 - \frac{v - 1}{S_a}$$

## 🚀 Запуск программы

### 1. Графический режим (GUI на Tkinter)
```bash
python lab2/laba2.py
```
*Интерфейс содержит редактор кода Perl, кнопки предустановленных примеров, таблицы вершин $V$, дуг $E$, элементов Джилба и сводный блок расчетов. Все таблицы поддерживают горячие клавиши (`Ctrl+C`, `Ctrl+A`) и контекстное меню для копирования.*

### 2. Консольный режим (CLI)
```bash
python lab2/laba2.py lab2/test_control_flow.pl
```
или с передачей через stdin:
```bash
cat lab2/test_control_flow.pl | python lab2/laba2.py
```
